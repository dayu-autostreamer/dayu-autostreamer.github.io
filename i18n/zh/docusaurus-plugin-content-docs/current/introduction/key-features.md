# 关键特性

大禹系统覆盖云边流式分析应用的完整生命周期：DAG 编排、运行时部署、调度、执行、观测与扩展。

## 基于 DAG 的 AI 服务流水线

应用使用有向无环图建模，而不是固定的线性链。DAG 可以分叉到多个 AI 服务、合并其结果，并把每个逻辑阶段放到不同节点执行。
工作流既可以在前端创建，也可以通过 `.dag` 文件导入和导出。

## 协同云边运行时

大禹系统将应用所需服务部署为协同运行时，并在运行时就绪后开放工作流。部署决策发生变化时，系统通过受控更新保持在途任务的
一致性。

## 自适应调度与部署

可插拔策略覆盖数据源选择、部署、数据配置、任务卸载与准入。内置基线和研究型调度器可以在同一运行时与可观测性模型下进行比较。
完整策略目录和扩展方式见[定制调度](/docs/developer-guide/how-to-develop/customize-scheduling)。

## Hook 驱动的扩展机制

开发者可以通过 hook 与模板扩展调度、数据生成、处理、监控和可视化行为，而不必重写运行时生命周期。

## 内置 AI 服务目录

服务目录包含检测、跟踪、分类、识别、模型切换与结构化交通分析。通用输入/输出形式使这些服务可以组合到不同 DAG 中。

## 可观测性与实验反馈

结果可视化支持帧、结构化叠加、曲线、拓扑、CDF 和 Gantt 视图。系统遥测覆盖计算、内存、网络、模型执行、调度与队列状态。
任务结果与系统快照可以导出用于离线分析。
