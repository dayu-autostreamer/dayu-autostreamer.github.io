# Dayu 社区

一起建设开放的云边协同流式分析平台。欢迎参与应用开发、系统建设、研究验证、文档编写和实际部署的伙伴。

## 我们的社区 {#our-community}

Dayu 由[南京大学](https://www.nju.edu.cn/) [Dislab](https://dislab.nju.edu.cn/) 发起，实验室的研究与开发构成了项目的起源。
[社区委员会](./committee.mdx)和[贡献者](./contributors.mdx)页面介绍项目背后的人员及其机构归属。

任何人都可以反馈问题、完善教程、评审方案、验证研究结果或贡献代码。
项目职责依据个人贡献与判断力确定，机构归属本身不赋予席位、投票权或仓库权限。
欢迎通过[社区治理](./governance.md)了解我们的协作方式。

## 找到你的参与入口 {#starting-point}

- **使用 Dayu：** 阅读[技术文档](/docs/)，通过[支持渠道](./support.md)提出疑问或反馈可复现的问题。
- **改进系统：** 向 [dayu-autostreamer/dayu](https://github.com/dayu-autostreamer/dayu) 贡献代码。
  仓库内的开发指南介绍实现细节、共享接口与测试方法。
- **完善网站：** 向[文档仓库](https://github.com/dayu-autostreamer/dayu-autostreamer.github.io)贡献教程、翻译、导航改进和博客。
- **帮助他人：** 参与评审、解释问题、完善示例或分享可复现的研究结果。

[参与贡献](./contributing.md)会帮助你选择合适的仓库，并准备第一份贡献。

## 研究与引用 {#research-and-citation}

在 [Dayu 博客](/blog/)中了解研究成果和项目动态。如果你的研究使用了 Dayu，
请参考[系统 README 中维护的引用信息](https://github.com/dayu-autostreamer/dayu#citation)。
研究合作请通过[支持与联系](./support.md#project-contact)交流。

## 行为准则 {#respectful-community}

我们致力于营造友好、相互尊重的社区环境。参与 Dayu 社区交流与协作时，
请遵循我们的[行为准则](https://github.com/dayu-autostreamer/dayu/blob/main/CODE_OF_CONDUCT.md)。

行为问题可通过支持页面列出的[私密反馈渠道](./support.md#conduct)报告。
