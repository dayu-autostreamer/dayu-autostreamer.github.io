# 社区委员会

Dayu 技术指导委员会（Technical Steering Committee，TSC）负责项目方向与治理，
维护者（Maintainers）负责日常技术工作。这是两类独立职责，同一个人可以同时承担。
[系统成员名单](https://github.com/dayu-autostreamer/dayu/blob/main/MAINTAINERS.md)记录项目角色，
[治理规则](./governance.md)说明任命和决策方式。

## 技术指导委员会 {#technical-steering-committee}

<CommunityMembers group="tsc" />

主席协调项目方向、治理和社区讨论。副主席协助议程、决策记录与后续工作，
并可在自身具备参与资格、主席无法参与或需要回避时主持讨论。这些职务不增加额外投票权、技术审批权或仓库权限。

## 维护者 {#maintainers}

<CommunityMembers group="maintainers" />

维护者共同承担系统仓库的技术质量、共享接口、兼容性、发布及贡献者支持职责，
协调具备相关能力的评审者，并帮助贡献者找到合适的参与入口。

## 参与贡献与承担职责 {#participate}

任何人都可以参与贡献或提供具备技术依据的评审。如果希望持续承担维护职责，
可向 Maintainer 介绍参与意愿和贡献，并遵循
[任命流程](https://github.com/dayu-autostreamer/dayu/blob/main/GOVERNANCE.md#appointments-and-delegation)。
机构信息用于记录成员归属，参与资格与职责依据个人贡献和判断力确定。

[贡献者页面](./contributors.mdx)记录更广泛的贡献致谢，[参与贡献](./contributing.md)提供入门指引。

## 网站维护 {#website-maintenance}

[网站维护者名单](https://github.com/dayu-autostreamer/dayu-autostreamer.github.io/blob/main/MAINTAINERS.md)
覆盖教程、翻译、站点代码和发布，其职责范围为本网站。
