# 支持与联系

请选择与问题对应的渠道。公开的问题与解答也能帮助其他用户和贡献者。

## 问题与贡献 {#questions}

| 问题类型 | 反馈入口 |
| --- | --- |
| 安装或使用咨询 | 先阅读[技术文档](/docs/)，再通过 [Dayu Issues](https://github.com/dayu-autostreamer/dayu/issues)提问。 |
| 系统缺陷或功能建议 | 使用 [Dayu Issue 模板](https://github.com/dayu-autostreamer/dayu/issues/new/choose)。 |
| 仓库内的实现文档或示例 | 在[系统仓库](https://github.com/dayu-autostreamer/dayu)提交 Issue 或 PR。 |
| 网站内容、导航或翻译 | 通过[网站 Issues](https://github.com/dayu-autostreamer/dayu-autostreamer.github.io/issues)反馈。 |
| 参与贡献、设计讨论或寻找评审者 | 阅读[参与贡献](./contributing.md)，在相关 Issue／PR 下交流，或联系[维护者](./committee.mdx#maintainers)。 |
| 治理、成员资格或职责 | 阅读[社区治理](./governance.md)；一般建议公开讨论，敏感人事事项私下联系无利益冲突的 Maintainer 或 TSC 成员。 |

反馈可复现的问题时，请提供 Dayu 版本、运行环境、相关配置、预期与实际行为以及最小复现步骤。
分享日志前请移除凭据、令牌、私有地址和个人信息。

## 安全漏洞报告 {#security}

疑似安全漏洞请通过私密渠道报告：

- 首选联系人：[Wenhui Zhou](mailto:whzhou@smail.nju.edu.cn)。
- 备用联系人：[Haoyang Su](mailto:shyshy@smail.nju.edu.cn)。
- 系统漏洞：遵循 [Dayu SECURITY.md](https://github.com/dayu-autostreamer/dayu/blob/main/SECURITY.md)，
  或提交[系统私密安全报告](https://github.com/dayu-autostreamer/dayu/security/advisories/new)。
- 网站漏洞：遵循[网站 SECURITY.md](https://github.com/dayu-autostreamer/dayu-autostreamer.github.io/blob/main/SECURITY.md)。

邮件主题请包含 `[SECURITY]`。如果报告涉及某位联系人，请联系另一位；
更进一步的利益冲突处理方式见安全政策。请勿在公开 Issue 或 PR 中披露漏洞细节。

## 行为问题反馈 {#conduct}

骚扰或其他行为问题，可私下联系 [Lei Xie](mailto:lxie@nju.edu.cn)
或 [Wenhui Zhou](mailto:whzhou@smail.nju.edu.cn)。

[行为准则](https://github.com/dayu-autostreamer/dayu/blob/main/CODE_OF_CONDUCT.md#enforcement)。

[系统支持指南](https://github.com/dayu-autostreamer/dayu/blob/main/SUPPORT.md)统一维护项目联系渠道。
