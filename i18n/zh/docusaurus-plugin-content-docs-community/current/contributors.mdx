# 贡献者与致谢

Dayu 的发展离不开代码、文档、翻译、测试、研究验证、评审、问题分类和用户支持。
感谢每一位参与者。

## 项目贡献者 {#project-contributors}

以下历史名单来自[系统成员记录](https://github.com/dayu-autostreamer/dayu/blob/main/MAINTAINERS.md#contributors)，
并非所有贡献者的完整列表。机构信息沿用该记录。

<CommunityMembers group="contributors" />

当前的治理和维护职责单独列于[社区委员会](./committee.mdx)页面。

## 各仓库的贡献记录 {#contribution-history}

- [Dayu 系统贡献记录](https://github.com/dayu-autostreamer/dayu/graphs/contributors)
- [文档网站贡献记录](https://github.com/dayu-autostreamer/dayu-autostreamer.github.io/graphs/contributors)

提交记录只能体现部分工作。有帮助的评审、可复现的问题报告、研究验证、翻译和支持同样值得认可。
如需修正信息或补充遗漏的致谢，请在对应仓库提交 Issue 并附上贡献链接。
不确定反馈位置时，可参考[支持与联系](./support.md)。

## 项目起源与持续参与 {#origins}

Dayu 由[南京大学](https://www.nju.edu.cn/) [Dislab](https://dislab.nju.edu.cn/) 发起。
我们记录项目起源，也认可每一位贡献者的工作。
欢迎其他高校、企业及独立开发者按照相同的[治理规则](./governance.md)参与并承担职责。

成员变更机构或暂停参与后，历史贡献仍会得到保留。
欢迎通过[参与贡献](./contributing.md)加入。
