# Support & Contact

Choose the channel that matches your question. Public answers help other users and contributors too.

## Questions and contributions {#questions}

| Topic | Where to go |
| --- | --- |
| Setup or usage | Start with the [documentation](/docs/), then ask in [Dayu issues](https://github.com/dayu-autostreamer/dayu/issues). |
| System bugs or feature proposals | Use the [Dayu issue templates](https://github.com/dayu-autostreamer/dayu/issues/new/choose). |
| Repository implementation docs or examples | Open an issue or PR in [the system repository](https://github.com/dayu-autostreamer/dayu). |
| Website content, navigation, or translation | Use [website issues](https://github.com/dayu-autostreamer/dayu-autostreamer.github.io/issues). |
| Contributions, design discussion, or finding a reviewer | Read [Contributing](./contributing.md), then comment on the relevant issue or PR or contact a [Maintainer](./committee.mdx#maintainers). |
| Governance, membership, or responsibilities | Read [Governance](./governance.md); discuss general proposals publicly and send sensitive personnel matters privately to a non-conflicted Maintainer or TSC member. |

For a reproducible problem, include the Dayu version, environment, relevant configuration, expected and actual behavior,
and minimal reproduction steps. Remove credentials, tokens, private endpoints, and personal data before sharing logs.

## Security reports {#security}

Report suspected vulnerabilities privately:

- Primary contact: [Wenhui Zhou](mailto:whzhou@smail.nju.edu.cn).
- Alternative contact: [Haoyang Su](mailto:shyshy@smail.nju.edu.cn).
- For system vulnerabilities: follow [Dayu SECURITY.md](https://github.com/dayu-autostreamer/dayu/blob/main/SECURITY.md)
  or submit a [private system advisory](https://github.com/dayu-autostreamer/dayu/security/advisories/new).
- For website vulnerabilities: follow [website SECURITY.md](https://github.com/dayu-autostreamer/dayu-autostreamer.github.io/blob/main/SECURITY.md).

Use `[SECURITY]` in an email subject. If a report involves one contact, use the other; the security policy
explains further conflict handling. Keep vulnerability details out of public issues and PRs.

## Conduct concerns {#conduct}

Report harassment or other conduct concerns privately to
[Lei Xie](mailto:lxie@nju.edu.cn) or [Wenhui Zhou](mailto:whzhou@smail.nju.edu.cn).
If a concern involves one contact, send it only to the other. If both are involved, use another non-conflicted
Maintainer. Follow the [Code of Conduct](https://github.com/dayu-autostreamer/dayu/blob/main/CODE_OF_CONDUCT.md#enforcement)
for independent handling, confidentiality, and reconsideration.

The [system support guide](https://github.com/dayu-autostreamer/dayu/blob/main/SUPPORT.md) maintains these project channels.
