Dayu 社区

一起建设开放的云边协同流式分析平台。欢迎参与应用开发、系统建设、研究验证、文档编写和实际部署的伙伴。

由南京大学 Dislab 发起

欢迎高校、企业及独立开发者参与贡献。

参与贡献 →从反馈、文档、测试或代码开始。认识维护团队 →了解社区成员及其承担的职责。寻求帮助 →找到使用咨询、问题反馈与合作入口。

我们的社区​

Dayu 由南京大学 Dislab 发起，实验室的研究与开发构成了项目的起源。 社区委员会和贡献者页面介绍项目背后的人员及其机构归属。

任何人都可以反馈问题、完善教程、评审方案、验证研究结果或贡献代码。 项目职责依据个人贡献与判断力确定，机构归属本身不赋予席位、投票权或仓库权限。 欢迎通过社区治理了解我们的协作方式。

找到你的参与入口​

  • 使用 Dayu： 阅读技术文档，通过支持渠道提出疑问或反馈可复现的问题。
  • 改进系统： 向 dayu-autostreamer/dayu 贡献代码。 仓库内的开发指南介绍实现细节、共享接口与测试方法。
  • 完善网站： 向文档仓库贡献教程、翻译、导航改进和博客。
  • 帮助他人： 参与评审、解释问题、完善示例或分享可复现的研究结果。

参与贡献会帮助你选择合适的仓库，并准备第一份贡献。

研究与引用​

在 Dayu 博客中了解研究成果和项目动态。如果你的研究使用了 Dayu， 请参考系统 README 中维护的引用信息。 研究合作请通过支持与联系交流。

请阅读并遵循行为准则。 支持页面分别提供行为问题的私密反馈和安全漏洞报告入口。
